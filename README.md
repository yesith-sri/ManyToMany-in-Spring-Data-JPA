# ManyToMany in Spring Data JPA

This project demonstrates how to implement and understand **Many-to-Many relationships** using **Spring Boot**, **Spring Data JPA**, and **Hibernate**.  
It includes examples of  **bidirectional** mappings, showing how entities can be efficiently linked in relational databases.
